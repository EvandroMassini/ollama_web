# Contribuindo

1. Crie um fork e uma branch descritiva.
2. Nunca inclua credenciais, bancos ou arquivos gerados.
3. Execute `composer lint` antes de enviar alterações.
4. Mantenha compatibilidade com PHP 8.1 e evite dependências desnecessárias.
5. Explique no pull request o problema, a solução e como ela foi testada.

Ao adicionar uma ferramenta, valide todos os argumentos no PHP e não permita que o modelo escolha caminhos, comandos ou operações de escrita no banco.
